# SettingSwitch

Baris izin pengemudi dengan sakelar, dan seluruh barisnya bisa disentuh.

- Props: `id` (wajib), `label`, `description`, `checked`, `onChange`, `disabled`.
- Layar pengaturan dipakai pengemudi saat mobil berhenti. Jangan arahkan pengemudi ke pengaturan selama perjalanan berjalan.
- Label adalah izin dan diawali "Boleh …": Boleh melewati lagu, Boleh menjeda, Boleh mengatur volume. Deskripsi menyebut tombol mana yang terpengaruh.
- Letakkan beberapa baris berurutan; garis pemisah sudah diatur stylesheet.
